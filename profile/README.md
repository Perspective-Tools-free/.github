## 🧠 Overview

Perspective Tools is a Photoshop panel for working with planes and angles: it draws perspective guides along real edges in the photo, then transforms, duplicates and retouches elements so they sit correctly on that plane. The product family is positioned as a perspective tools for photoshop toolset for Windows workflows.

Perspective Tools works as a plug-in suite on Windows 10 and Windows 11 and is installed alongside a host application such as Adobe Photoshop CC 2019 or newer.

## 🚀 Key Features

| Feature | Description |
| --- | --- |
| 📐 Plane Guides | Guides are drawn along the perspective of a surface using two reference lines. |
| 🔄 Transform on Plane | Objects are scaled and skewed according to the plane instead of by eye. |
| 🧱 Duplicate Along Plane | Repeats an element step by step so the spacing follows the vanishing point. |
| 🩹 Plane Retouch | Clone and heal strokes are projected onto the surface with correct distortion. |
| 🎯 Grid Overlay | Numeric grid on the plane helps to place repeated structures accurately. |
| 🧩 Layer Output | Each operation returns as a smart object or layer that can be re-edited. |

## Additional Information for Windows Users

Settings created in Perspective Tools are stored in the plug-in's own preset folder, so a reinstall keeps user presets and replaces only program files.

Removing the plug-in goes through the host application's plug-in manager or the Windows uninstall entry, depending on how it was registered.
